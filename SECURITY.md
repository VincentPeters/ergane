# Security

Ergane runs entirely in the browser. The input it does not control is kit files, share links and
component JSON, and the core clamps all of them.

To report a problem, use GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/VincentPeters/ergane/security/advisories/new).
Please do not open a public issue. You can also write to hello@vinnie.studio.

You will get a reply within a week. Only the version live at https://ergane.vinnie.studio is supported.
